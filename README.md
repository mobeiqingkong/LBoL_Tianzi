# 比那名居天子 (Tenshi Hinanawi) — LBoL 角色 Mod

《东方光耀夜 / Lost Branch of Legend》1.8.0 可游玩角色 Mod。

## 角色定位

- 生命值 **65**，初始金钱 **80**，初始费用 **2白 2红**，左色白 / 右色红
- 难度：A = 1，B = 2
- 使用**游戏内置天子模型**（`EnemyUnits.Character.Tianzi`，已翻转朝向）

## 核心机制

| 机制 | 说明 |
|---|---|
| 临时生命值 | 独立于生命值上限的战斗内生命池，上限 15。受击时**优先于格挡与护盾**扣减 |
| 自愈 | 每回合恢复等量生命值，回合结束时层数 −1 |
| 天气 | 共 8 种（快晴 / 雾雨 / 云天 / 苍天 / 雹 / 浓雾 / 台风 / 无风）。同一时刻只有一种天气生效 |

## 初始展品

- **A：仙桃（光耀）** — 提供 1 点白色费用。每次受到影响生命值的任意伤害时恢复 1 点生命值并获得 1 点 p点
- **B：绯想之剑（光耀）** — 提供 1 点红色费用。每回合首次对敌人施加负面状态时追加 1 层虚弱；目标已有虚弱则改为易伤

## 符卡

- **A：气符「无念无想的境界」** — p点上限 180 / 每次 60。获得 1 回合天衣无缝 + 5 点临时生命值，并移除自身所有负面状态
- **B：彩符「天穹虹华之剑」** — p点上限 200 / 每次 100。随机释放一种天气（3 回合），对目标造成 45 点伤害（每场战斗首次 55 点）

## 支付

安装 `BepInEx 5.4.21` 与 `LBoL-Entity-Sideloader`，把本 zip 解压到 `BepInEx/plugins/TianziMod/` 即可。
